01 About

Business logic that holds up — from the model to the last screen.

I’m an Odoo ERP developer and web developer from Ahmedabad, building on Odoo v14 to v20.

Results-driven developer with experience designing, developing and implementing web applications and ERP solutions — proficient in full-stack development and Odoo customization.

At Warloak Technology I delivered 20+ custom Odoo modules and customizations for live clients across v14, v16, v17, v18 and v19, and worked on a POS mobile application. Today I’m a Jr. Software Developer at Admionix Solutions, building apps on Odoo v20.

Alongside ERP work I build React.js web projects, run the official Indrashil University website, and use AI tools — Claude, ChatGPT, OpenCode and Grok — to move faster without lowering the bar.
